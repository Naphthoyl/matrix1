# Matrix—Работа с матрицами
Программа реализует работу с квадратными матрицами целых чисел и циклическим двусвязным списком.

Каждый узел списка содержит объект класса Matrix, представляющий квадратную матрицу размером n × n.

Программа позволяет хранить несколько матриц в списке, вычислять след каждой матрицы и выводить содержимое списка.

# Возможности
Создание квадратных матриц целых чисел.
Ввод элементов матриц из текстового файла.
Сложение двух матриц одинакового размера.
Умножение двух матриц одинакового размера.
Вычисление следа матрицы — суммы элементов главной диагонали.
Хранение матриц в циклическом двусвязном списке.
Вставка и удаление элементов списка.
Перемещение по списку вперёд и назад.
Получение и изменение элементов списка.
Копирование списка и матриц.
Используемые инструменты
Язык программирования: C++
Стандартная библиотека: iostream, fstream
Основные концепции: классы, динамическая память, конструкторы и деструкторы, перегрузка операторов, конструктор копирования, циклический двусвязный список.
Структура программы
Класс Matrix
Отвечает за хранение и обработку квадратных матриц.

# Основные методы:

input() — чтение элементов матрицы из файла.
show() — вывод матрицы на экран.
operator+() — сложение матриц.
operator*() — умножение матриц.
sledMatrix() — вычисление следа матрицы.
Конструктор копирования и оператор присваивания — копирование матриц.
Класс Node
Представляет узел списка. Содержит:

data — матрицу.
prev — указатель на предыдущий узел.
next — указатель на следующий узел.
Класс List
Реализует циклический двусвязный список с фиктивным базовым узлом.

# Основные операции:

ins_before() и ins_after() — вставка матриц.
del_before() и del_after() — удаление узлов.
get_before() и get_after() — получение матриц.
set_before() и set_after() — изменение матриц.
step_forward() и step_backward() — перемещение по списку.
go_to_beg() и go_to_end() — переход к началу и концу.
sum() и mul() — сложение и умножение матриц, находящихся в позициях before и after.
sled() — вычисление следа каждой матрицы в списке.
show() — вывод содержимого списка.
Формат входного файла
Программа читает данные из файла text.txt, который должен находиться в рабочей директории программы.

# Формат файла:

# Количество матриц.
Для каждой матрицы — размер n.
Далее — n × n целых чисел, записанных построчно.
Пример text.txt
3
2
1 2
3 4
3
1 0 2
0 1 3
4 5 6
2
5 6
7 8
В этом примере задаются три матрицы: две матрицы размера 2 × 2 и одна матрица размера 3 × 3.

Запуск программы
Скомпилируйте исходный файл с помощью компилятора C++.
Поместите text.txt в рабочую директорию программы.
Запустите программу.
Результат работы
Программа вычисляет след каждой матрицы и выводит полученные значения. Затем выводится содержимое матриц, хранящихся в списке.

След квадратной матрицы вычисляется по формуле:

[ \operatorname{tr}(A)=\sum_{i=0}^{n-1}a_{ii} ]

Для первой матрицы из примера:

[ \operatorname{tr}(A)=1+4=5 ]

Для второй матрицы:

[ \operatorname{tr}(B)=1+1+6=8 ]

Для третьей матрицы:

[ \operatorname{tr}(C)=5+8=13 ]

Обработка ошибок
Программа проверяет:

Успешность открытия файла text.txt.
Положительность количества матриц.
Если файл не удалось открыть или количество матриц некорректно, программа выводит сообщение об ошибке.
