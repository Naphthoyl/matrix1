# Matrix + List

Учебный проект на C++. В нём два основных класса: `Matrix`, то есть квадратная матрица, и `List`, двусвязный список, который хранит матрицы. У списка есть два «курсора», `before` и `after`, между которыми можно вставлять и удалять элементы.

Раньше весь код лежал в одном файле. Теперь я разложил его по папкам, как принято в нормальных проектах, и добавил сборку через CMake.

## Что где лежит

```
.
├── CMakeLists.txt
├── main.cpp          # точка входа
├── text.txt          # входные данные
├── include/          # заголовки (.h): объявления классов
│   ├── matrix.h
│   ├── node.h
│   └── list.h
└── src/              # реализации (.cpp)
    ├── matrix.cpp
    ├── node.cpp
    └── list.cpp
```

Каждый класс (`Matrix`, `Node`, `List`) живёт в своей паре файлов: в `include/` его объявление, в `src/` реализация методов.

## Как собрать и запустить

### Через g++

Из корня проекта:

```
g++ -std=c++17 -Wall -Iinclude main.cpp src/matrix.cpp src/node.cpp src/list.cpp -o app
./app
```

Флаг `-Iinclude` нужен, чтобы компилятор искал заголовки в папке `include/`. Без него `#include "matrix.h"` не сработает.

### Через CMake

```
cmake -S . -B build
cmake --build build
cd build
./app
```

CMake собирает две статические библиотеки (`matrix` и `list`) и линкует их с `main.cpp` в программу `app`. Файл `text.txt` он сам копирует в `build/`, так что программа находит его при запуске оттуда.

## Входные данные

Программа читает файл `text.txt`. Формат такой:

```
2        <- сколько всего матриц
2        <- размер первой матрицы
1 2
3 4
3        <- размер второй матрицы
1 0 0
0 1 0
0 0 1
```

Сначала идёт количество матриц, потом для каждой её размер и сами элементы.
